Chemistry: stereoisomerism, hapticity, phase boundaries

Chemistry data modelling in microservices is hard because molecules are not flat. Stereoisomers that share a SMILES string are different drugs; transition metal complexes have haptic bonds that break 1:1 valence rules; and near-critical thermodynamic states cause numeric overflow. This page covers the edge cases and corner cases, and the dimensional model that handles them.

The core insight

SMILES is a presentation format, not an identity. InChI is the identity. Its layered design (formula, connections, hydrogen, stereochemistry, isotope, charge) means two enantiomers produce different InChI keys but the same SMILES. Use InChIKey as the conformed dimension key and the stereochemistry problem largely disappears.

For hapticity and phase boundaries, the pattern is the same: promote the hard part to a dimension. Bond type becomes a dimension (not an attribute). Phase region becomes a dimension (not a computed column). This lets the fact table stay narrow and the complex logic lives in the dimension, where it can evolve without breaking existing fact rows.

Edge cases

Three chemistry sub-domains, three data-modelling failures, three dimensional solutions.

Stereoisomerism Flattener
Organic Chemistry
Problem

A microservice fails to represent geometric (cis/trans) or optical (R/S enantiomers) isomers distinctly because the database schema relies purely on standard flat SMILES strings, which frequently drop stereochemical flags.

Impact

Two molecules with identical SMILES but opposite chirality (e.g. (R)-thalidomide vs (S)-thalidomide) collapse into one row. Drug safety analysis fails silently — the teratogenic enantiomer is indistinguishable from the therapeutic one.

Dimensional solution

Use InChI (International Chemical Identifier) as the conformed dimension key, not SMILES. InChI encodes stereochemistry in a standardised, canonical form. Add a dim_stereochemistry dimension with layers for tetrahedral (t), double-bond (b) and other stereo flags. The fact table references the InChI key; the dimension carries the full stereo description.

Inorganic & Organometallic Chemistry
Problem

Representing transition metal complexes (e.g. ferrocene, cisplatin) where a single central metal atom forms coordinate covalent bonds with varying hapticity (η⁵) or multi-atom ligands that break standard 1:1 atomic valence modelling rules.

Impact

A 1:1 bond table cannot represent ferrocene (Fe η⁵-bonded to two cyclopentadienyl rings). The molecular graph fragments; ETL silently drops multi-haptic bonds or creates phantom atoms. Coordination number analysis returns wrong results.

Dimensional solution

Model bonds as a many-to-many relationship with a bond_type attribute (single, double, triple, aromatic, dative, η¹–η⁸ haptic). Use a dim_bond_type dimension. The fact_molecular_structure table has one row per (molecule × bond × role), not per atom-pair. Hapticity is an attribute of the bond, not the atom.

Dynamic State Transition Boundaries
Physical Chemistry
Problem

Extreme thermodynamics modelling near the critical point or triple point where a substance manifests dual properties (supercritical fluid), causing numeric overflow/underflow or division-by-zero errors in continuous phase equation models.

Impact

The Peng-Robinson equation of state divides by (V-b) near the critical volume. At the critical point, V→Vc and the denominator approaches zero. Floating-point overflow produces NaN; the fact table stores NaN; downstream queries return wrong aggregates.

Dimensional solution

Add a dim_phase_region dimension (subcritical-liquid, subcritical-gas, supercritical, critical-point, triple-point). Fact rows near phase boundaries carry a phase_region_key and a stability_flag. Use arbitrary-precision decimals (Python Decimal or Rust rug) for near-critical calculations; store the standard double-precision result for fast queries and the high-precision result for reproducibility.

Corner case: The Metamorphic Biomolecule Event

An organometallic enzyme modifier is undergoing a physical reaction at high temperature and pressure while shifting its stereochemical configuration.

Organic

Dynamically tracking a changing molecular graph structure (bond breaking/forming, stereochemistry flipping)

Physical

Highly volatile physical-state variables (temperature, pressure, phase region shifting near critical point)

Inorganic

Coordinate/dative multi-ligand bounds changing as the metal centre gains/loses ligands

Failure mode

Split-brain validation failure — three microservices (molecular-graph, thermodynamic-state, coordination-geometry) each hold a partial view of the molecule. Without a saga coordinator, they disagree on whether the transition is valid. The warehouse receives three inconsistent event streams.

Solution

Implement a saga with a compensating action per service. The molecular-graph service emits a molecule.transformed event; the thermodynamic service validates the transition is physically possible; the coordination service validates the new ligand set is geometrically feasible. A saga coordinator holds the workflow_run_key and only commits the fact row when all three services agree. The dim_workflow_run dimension tracks the saga state.

Dimensional model (SQL DDL)
InChI-keyed molecule dimension, stereochemistry dimension, haptic bond type, phase region with precision tier.
-- Chemistry dimensional model — handles stereoisomerism, hapticity, phase boundaries

-- Conformed dimension: molecule (InChI-keyed, not SMILES)
CREATE TABLE dim_molecule (
  molecule_key     INT PRIMARY KEY,
  inchi_key        VARCHAR(27) UNIQUE,  -- InChIKey: 14-char hash + 2 stereo layers
  inchi            TEXT,                -- full InChI with stereo layers
  canonical_smiles TEXT,                -- for tooling that needs SMILES
  molecular_formula VARCHAR(100),
  molecular_weight DECIMAL(10,3),
  cas_number       VARCHAR(20)
);

-- Stereochemistry dimension (InChI /t and /b layers)
CREATE TABLE dim_stereochemistry (
  stereo_key       INT PRIMARY KEY,
  molecule_key     INT REFERENCES dim_molecule,
  stereo_type      VARCHAR(20),  -- tetrahedral | double-bond | spiro | polyhedral
  stereo_layer     VARCHAR(10),  -- /t, /b, /s
  stereo_value     VARCHAR(50),  -- e.g. "1+,2-" for R,S at centres 1,2
  is_canonical     BOOLEAN       -- is this the canonical enantiomer?
);

-- Bond type dimension (handles hapticity)
CREATE TABLE dim_bond_type (
  bond_type_key    INT PRIMARY KEY,
  bond_type        VARCHAR(20),  -- single | double | triple | aromatic | dative
  hapticity        SMALLINT,     -- NULL for non-haptic, 1-8 for η¹-η⁸
  is_multicenter   BOOLEAN       -- true for haptic/agostic/3c-2e bonds
);

-- Phase region dimension (handles critical/triple points)
CREATE TABLE dim_phase_region (
  phase_region_key INT PRIMARY KEY,
  region           VARCHAR(30),  -- subcritical-l | subcritical-g | supercritical
  is_boundary      BOOLEAN,      -- true at critical/triple point
  precision_tier   VARCHAR(20)   -- float64 | decimal128 | arbitrary
);

-- Fact: molecular structure (one row per molecule × bond × role)
CREATE TABLE fact_molecular_structure (
  structure_key    BIGINT PRIMARY KEY,
  molecule_key     INT REFERENCES dim_molecule,
  stereo_key       INT REFERENCES dim_stereochemistry,
  atom1_key        INT,
  atom2_key        INT,           -- NULL for haptic bonds (atom group)
  bond_type_key    INT REFERENCES dim_bond_type,
  workflow_run_key INT,           -- provenance
  bond_order       DECIMAL(3,1)   -- 1.0, 1.5, 2.0, or fractional for delocalised
);

-- Fact: thermodynamic property (handles near-critical states)
CREATE TABLE fact_thermodynamic_property (
  property_key     BIGINT PRIMARY KEY,
  molecule_key     INT REFERENCES dim_molecule,
  phase_region_key INT REFERENCES dim_phase_region,
  eos_key          INT,           -- equation of state used
  precision_key    INT,           -- float64 / decimal128 / arbitrary
  temperature_k    DECIMAL(10,4),
  pressure_pa      DECIMAL(15,4),
  volume_m3_mol    DECIMAL(15,8), -- high precision near Vc
  enthalpy_j_mol   DECIMAL(15,4),
  stability_flag   VARCHAR(20)    -- stable | near-critical | unstable | NaN-suppressed
);
Microservices decomposition

Each edge case maps to a microservice behind the bus matrix:

  • molecular-graph-service — owns dim_molecule, dim_stereochemistry, fact_molecular_structure. Emits molecule.transformed events.
  • thermodynamic-service — owns dim_phase_region, fact_thermodynamic_property. Validates phase transitions; uses arbitrary precision near critical points.
  • coordination-geometry-service — owns dim_bond_type, dim_ligand. Validates haptic and dative bonds are geometrically feasible.
  • saga-coordinator — orchestrates the metamorphic biomolecule event; holds the workflow_run_key; commits the fact row only when all three services agree.
