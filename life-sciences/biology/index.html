Biology: alternative splicing, taxonomic graphs, HGT

Biological data modelling fails when it assumes linearity. Genes produce multiple transcripts (alternative splicing); taxonomy is a graph with horizontal gene transfer, not a tree; retroviral genomes grow in length. This page covers the edge cases and corner cases, and the dimensional model that handles them.

The core insight

Biology is not hierarchical — it is a graph. Taxonomy is a graph (parent-child with cross-kingdom HGT edges). Gene-to-protein is a graph (one gene, many transcripts, many isoforms). Forcing these into rigid hierarchies destroys the signal that matters most: alternative splicing drives protein diversity; horizontal gene transfer drives antibiotic resistance.

The dimensional answer: promote the graph to a dimension. Self-referencing dim_taxon with parent_taxon_key handles the tree; dim_hgt_event handles the cross-edges. SCD2 on dim_transcript handles isoform evolution. The fact table stays narrow and references the graph node (transcript, taxon), not the hierarchy level.

Edge cases

Two biology sub-domains, two data-modelling failures, two dimensional solutions.

Alternative Splicing & Polymorphisms
Molecular Biology
Problem

A genomics microservice mapping DNA sequencing data fails because a specific gene model cannot handle overlapping non-sequential open reading frames (ORFs), nested genes, or hyper-variable single nucleotide polymorphisms (SNPs) across different cell expressions.

Impact

A gene with 3 alternatively-spliced transcripts produces 3 protein isoforms. A flat gene→protein table stores only one. RNA-seq quantification assigns reads to the wrong transcript. SNP effect prediction uses the wrong reference exon.

Dimensional solution

Model the gene-transcript-exon hierarchy as a Type 2 slowly changing dimension with effective dates per transcript version. Use a fact_variant_call table with a transcript_key FK (not gene_key) so the same SNP can have different effects on different isoforms. Add a dim_splice_event dimension to track exon inclusion/skipping.

Taxonomic Collapse & Reclassification
Biology (Taxonomy)
Problem

An ecological survey or macro-biology microservice relies on a hardcoded rigid hierarchy (Kingdom → Phylum → Class), which fails when a newly sequenced microorganism triggers a global phylogenetic tree restructure or possesses fluid horizontal gene transfer pathways that ignore vertical lineage models.

Impact

A newly discovered archaeon shares 60% of its genome with bacteria (horizontal gene transfer) but 40% with archaea. A rigid hierarchy forces it into one kingdom, losing the HGT signal. When NCBI Taxonomy restructures a clade, every downstream fact row needs its taxon_key updated — a massive ETL job.

Dimensional solution

Model taxonomy as a graph (adjacency list) not a hierarchy. dim_taxon has parent_taxon_key (self-referencing) and a rank (superkingdom, phylum, class, order, family, genus, species). Add a dim_hgt_event table for horizontal gene transfer events — these are first-class facts, not errors. Taxonomic reclassification is an SCD2 change on dim_taxon; old fact rows keep their original taxon_key and gain a current_taxon_key via a bridge table.

Corner case: The Viral RNA Retro-Mutation Leak

An airborne retrovirus undergoes dynamic mutation via continuous sequence insertions while cross-infecting an organism across diverse taxonomic kingdoms.

Molecular Biology

Unstable genetic sequence length that exceeds standard indexing limits — the viral genome grows as reverse transcriptase inserts repeats, breaking fixed-length VCF indexing

Taxonomy

Ambiguous, dynamically reclassifying taxonomic biological entity — the virus jumps from animal to plant reservoir, its host range expanding faster than the taxonomy service can reclassify

Microservice boundary

Separate microservice boundary contexts — the genomics service sees a sequence, the taxonomy service sees a host-pathogen interaction, the epidemiology service sees a transmission event

Failure mode

The variant-calling pipeline crashes on the growing sequence (VCF line length exceeds limit). The taxonomy service cannot place the virus because its host is a plant but its vector is an animal. The epidemiology service sees transmissions but cannot join them to a stable taxon key. Three services, three partial truths, no consistent fact row.

Solution

Use a variable-length sequence store (not VCF) for retroviral genomes — a document store (MongoDB) or a graph store (Neo4j) for the sequence + its insertion history. The dim_taxon graph handles cross-kingdom hosts via the dim_hgt_event table (horizontal transfer is the norm for viruses, not the exception). A saga coordinator holds the outbreak_run_key; the fact_infection_event row is committed only when sequence, taxonomy and epidemiology services all agree on a consistent view. The warehouse stores the sequence-length-change events as facts (dim_insertion_event), not as errors.

Dimensional model (SQL DDL)
Self-referencing dim_taxon graph, SCD2 dim_transcript, HGT as first-class fact, variable-length variant alleles.
-- Biology & molecular biology dimensional model
-- Handles alternative splicing, taxonomic graphs, horizontal gene transfer

-- Gene → Transcript → Exon hierarchy (SCD2 on transcript)
CREATE TABLE dim_gene (
  gene_key         INT PRIMARY KEY,
  hgnc_id          VARCHAR(20) UNIQUE,
  ensembl_id       VARCHAR(30),
  gene_symbol      VARCHAR(50),
  chromosome       VARCHAR(5),
  start_pos        BIGINT,
  end_pos          BIGINT,
  strand           CHAR(1)  -- + or -
);

CREATE TABLE dim_transcript (
  transcript_key   INT PRIMARY KEY,
  gene_key         INT REFERENCES dim_gene,
  ensembl_transcript_id VARCHAR(30),
  transcript_type  VARCHAR(20),  -- protein_coding, lncRNA, pseudogene
  effective_from   DATE,  -- SCD2: when this isoform was annotated
  effective_to     DATE,
  is_current       BOOLEAN
);

CREATE TABLE dim_exon (
  exon_key         INT PRIMARY KEY,
  transcript_key   INT REFERENCES dim_transcript,
  exon_rank        SMALLINT,      -- order in the transcript
  exon_start       BIGINT,
  exon_end         BIGINT,
  is_alternative   BOOLEAN        -- true if exon is skipped in some isoforms
);

-- Taxonomy as a self-referencing graph (NOT a rigid hierarchy)
CREATE TABLE dim_taxon (
  taxon_key        INT PRIMARY KEY,
  ncbi_taxon_id    INT UNIQUE,
  scientific_name  VARCHAR(200),
  rank             VARCHAR(30),   -- superkingdom, phylum, class, order...
  parent_taxon_key INT REFERENCES dim_taxon,  -- self-reference = graph
  effective_from   DATE,          -- SCD2: reclassification tracking
  effective_to     DATE,
  is_current       BOOLEAN
);

-- Horizontal gene transfer (first-class fact, not an error)
CREATE TABLE dim_hgt_event (
  hgt_key          INT PRIMARY KEY,
  donor_taxon_key  INT REFERENCES dim_taxon,
  recipient_taxon_key INT REFERENCES dim_taxon,
  gene_key         INT REFERENCES dim_gene,
  transfer_type    VARCHAR(20),   -- conjugation, transduction, transformation
  evidence         VARCHAR(20)    -- phylogenetic, compositional, experimental
);

-- Fact: variant call (per-transcript, not per-gene)
CREATE TABLE fact_variant_call (
  call_key         BIGINT PRIMARY KEY,
  transcript_key   INT REFERENCES dim_transcript,  -- NOT gene_key
  sample_key       INT,
  position         BIGINT,
  ref_allele       VARCHAR(200),   -- variable length for indels
  alt_allele       VARCHAR(200),
  quality          DECIMAL(5,2),
  workflow_run_key INT,
  is_insertion     BOOLEAN,        -- true for retroviral repeat insertions
  insertion_length INT             -- NULL for SNPs, length for indels
);
Microservices decomposition
  • genomics-service — owns dim_gene, dim_transcript, dim_exon, fact_variant_call. Handles variable-length alleles via document store fallback.
  • taxonomy-service — owns dim_taxon (graph), dim_hgt_event. Handles reclassification via SCD2; HGT is a fact, not an error.
  • epidemiology-service — owns fact_infection_event, dim_outbreak. Joins to taxonomy via taxon_key but tolerates ambiguity.
  • saga-coordinator — holds outbreak_run_key; commits the infection fact only when sequence, taxonomy and epidemiology agree.
