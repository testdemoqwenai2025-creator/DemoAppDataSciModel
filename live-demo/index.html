Live demo: synthetic data + event stream

Two mini-services run alongside the Next.js app to demonstrate the distributed platform in action. The synthetic-data-service generates realistic fact rows for the three scientific domains. The event-stream-service emits a real-time WebSocket stream of simulated instrument events. Both are reachable through the gateway using the XTransformPort query parameter.

Try it now — client-side demos (no server needed)
The sandbox services aren't reachable on GitHub Pages, but these demos run entirely in your browser. See the same data, queries, and analytics that the live sandbox produces.
See provenance queries and workflow_run_key unification with synthetic data.

Static deployment — mini-services not reachable

You're viewing the static GitHub Pages deployment. The synthetic-data-service, event-stream-service and feature-store-service run alongside the Next.js app in the live sandbox only — they cannot be reached from GitHub Pages. The tabs below show seeded demo data so you can still see what the interface looks like. For the full live experience, run the project locally with bun run dev + bash .zscripts/start-mini-services.sh.

What you are seeing

The synthetic-data-service on port 3030 returns deterministic, seedable fact rows — the same query always returns the same data, which is what reproducible science demands. Try changing the seed to see a different realisation of the same domain.

The event-stream-service on port 3003 emits a live WebSocket stream of simulated instrument events. Each event carries a trace_id and workflow_run_key — the same identifiers that would join to dim_workflow_run in the real platform. Watch the stream: climate, genomics and astronomy events interleave on a single broker, exactly as the architecture diagrams show.

Natural Language Query — ask your warehouse in English
Ask a question in plain English. An AI translates it to SQL, executes it against the dim_workflow_run provenance dimension (28 seeded runs), and returns results as a table.
The warehouse has 28 seeded workflow runs across 8 pipelines (cesm2-regrid, gatk-haplotypecaller, rubin-alert-stream, fmriprep, deepvariant, cmip6-analysis, vera-rubin-cosmology, bids-mri-preproc) and 4 domains (climate, genomics, astronomy, neuroimaging). Try a sample question above.
Upload your own scientific data
Drop a CSV, TSV, JSON or text file — or link a URL. DSModelPro will parse it, infer column types, compute statistics, and suggest a fact table grain. This works in both sandbox and static (GitHub Pages) modes.Expected: CSV, TSV, JSON, JSONL, text — up to 50 MB
Lazy evaluation: streams via File.stream() + TextDecoderStream — never loads the full file into memory. Statistics use online algorithms (Welford's mean, running min/max).
