Data Platform

Unstructured & semi-structured data platform

Real Python running in a pipeline-service (port 3010) — not displayed code, but actual executed Python. ETL cleansing, spaCy NER entity extraction, rapidfuzz entity resolution/deduplication, BeautifulSoup web scraping, and unstructured-to-structured extraction. All endpoints are live and callable. Healthcare and pharma examples throughout.

Why this page exists

Most data platforms handle structured data well (tables, SQL, star schemas). The hard part is unstructured and semi-structured data — clinical notes, archival descriptions, web pages, XML, JSON, free text. This page demonstrates real Python processing of all of these: spaCy extracts entities from clinical narratives, rapidfuzz resolves duplicate patient records, BeautifulSoup scrapes web pages, and the ETL pipeline cleanses and validates healthcare data.

Every endpoint runs on a live Python service (pipeline-service, port 3010) with pandas, numpy, spaCy, rapidfuzz, recordlinkage, beautifulsoup4 and duckdb installed. Click any "Run" button to execute real Python.

1. ETL Cleansing Pipeline (real Python, pandas)
Upload CSV → cleanse (whitespace, dates) → validate (nulls) → deduplicate → enrich (year, decade, row hash). Healthcare sample pre-loaded.
2. Entity Extraction (real spaCy NER)
Extract persons, organisations, dates, GPE (places) from unstructured clinical text. Healthcare narrative pre-loaded.
3. Entity Resolution / Deduplication (real rapidfuzz)
Fuzzy-match duplicate patient records using token sort ratio. Detects "John Smith" = "Jon Smith" = "J Smith". Healthcare patient data pre-loaded.
4. Unstructured → Structured Extraction (NER + regex)
Extract structured fields from unstructured clinical text: NHS numbers, emails, phones, dates, postcodes, amounts, percentages, URLs. In production, this would call an LLM API.
5. Web Scraping (real BeautifulSoup)
Fetch a URL, parse HTML, extract title, headings, links, tables, images, and text content. NHS conditions page pre-loaded as example.
